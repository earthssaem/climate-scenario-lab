# 🌏 기후변화 시나리오 탐구실

고등학생이 **기상청 SSP 기후변화 시나리오 자료**로 우리나라의 미래 기후를 지역·기후요소·시기별로 직접 비교하는 탐구 웹앱입니다.
통합과학 탐구 「기후 변화로 인한 생태계와 지구계의 미래 시나리오 구상하기」와 연결됩니다.

> ## 데이터 상태
> `data/`에는 **실제 자료**가 들어 있습니다(`manifest.version` = `kma-2026-11-10`, 모든 파일 `"mock": false`).
> 기상청 원본에서 `build_app_data.py`로 가공한 `app-data`를 그대로 넣었고, 공식 기간값 1,330건(현재기후·20년 기간값·전국 10년 값)이 원본 화면표(`official_periods.json`)와 모두 일치하는 것을 확인했습니다.
> 예시(가짜) 데이터는 `data-mock/`에만 만들어지며(`tools/make_mock.py`), 저장소·배포에 넣지 않습니다. 예시 데이터를 불러오면 화면 맨 위 경고 띠, 지도·그래프 워터마크, 숫자 옆 "예시" 배지가 함께 보입니다.

---

## 실행하기

빌드 과정이 없는 정적 사이트입니다(순수 HTML/CSS/JS, ES 모듈).
ES 모듈과 `fetch`를 쓰기 때문에 파일을 더블클릭(`file://`)해서는 열리지 않습니다. 간단한 웹 서버로 엽니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. 배포는 GitHub → Vercel(정적 사이트, 빌드 명령 없음)입니다.

외부에서 받는 것은 CDN 두 곳뿐입니다: Chart.js 4.5.1 + chartjs-plugin-annotation 3.1.0(그래프), Pretendard(글꼴).
분석·추적 스크립트, 입력칸, `localStorage`는 없습니다. 모든 상태는 메모리에만 있고 새로고침하면 기본값으로 돌아갑니다.

## 화면 구성 (지도·그래프 중심)

큰 지도 두 장과 큰 시계열 그래프를 만지면서 "어디서"와 "언제"를 발견하는 화면입니다. 디벗 가로(1280×800)에서는 스크롤 없이 지도 두 장 + 숫자 카드 + 그래프가 한 화면에 보이고(지도·그래프가 화면의 약 60% 이상), 기간별 표와 푸터는 아래로 스크롤해야 보입니다.

```
⚠ 예시 데이터 띠
[제목]  평균기온  강수량  폭염  열대야  한파  ⓘ                 (값|변화량) (mm|%) [⛶ 전체화면]   ← 머리 막대(흰 바탕)
         ‾‾‾‾‾‾‾‾ (선택한 기후요소만 밑줄)
(하나만 보기|두 개 비교) [A ● SSP1-2.6 ▾] vs [B ● SSP5-8.5 ▾]   현재(2000~2019) 전반기 중반기 2061~2080 ⓘ [후반기] (2014년 보기 ✕)   ← 공통 조건
┌ [분석 지역: 서울 ▾] 지도를 눌러 바꿀 수 있어요 [전국으로][+ 비교 지역] (나란히|차이) ┐┌ 서울 · 평균기온 · 현재 대비 변화량              ┐
│  A 지도            B 지도                          ││ ┌ 후반기(2081~2100) · 20년 평균   [▾ 기간별 표] ┐ │ ← 숫자 카드
│                                                    ││ │ A ● SSP1-2.6  B ● SSP5-8.5  두 시나리오 차이 │ │
│                                                    ││ │ +2.4℃        +6.7℃        +4.3℃            │ │
│                                                    ││ └ (15.5℃)      (19.8℃)                       ┘ │
│                                                    ││ ☐ 4개 모두 보기 ☐ 과거 관측 보기(1912~) ☐ 20년 평균선 표시 ⓘ │
│                                                    ││  시계열 그래프 (안쪽 왼쪽 위 범례)        │
│  공통 범례 ⓘ (0 = 흰색)                            ││  한 줄 안내                              │
└────────────────────────────────────────────────────┘└──────────────────────────────────────────┘
```

- **상단 디자인 원칙**: 역할마다 모양을 나눕니다 — 기후요소는 밑줄 탭, 시나리오는 드롭다운, 기간은 가벼운 선택 버튼, 값/변화량·mm/%·나란히/차이는 분할 버튼. 모든 조작은 높이 44px·모서리 10px·글자 16px(그룹 이름표 14px)로 통일하고, 고른 항목에 진한(검은) 채움 바탕을 쓰지 않습니다(밑줄, 흰 바탕 + 테두리로 구분). 그룹 사이에는 40px 여백을 둡니다.
- **머리 막대(흰 바탕)**: 제목 · 기후요소 밑줄 탭(고른 항목만 진한 글자 + 밑줄, 나머지는 차분한 회색) · 요소 설명 ⓘ · 오른쪽 끝 [값|변화량](강수량 변화량이면 [mm|%]) · `[전체화면]`(브라우저 전체화면 켜기/끄기, 켜져 있으면 "전체화면 끝내기". 지원하지 않는 브라우저(아이폰 사파리 등)에서는 숨김. 1199px 이하에서 mm/%까지 있으면 아이콘만). 분할 버튼은 옅은 회색 틀 안에서 고른 칸만 흰 바탕입니다.
- **[하나만 보기 | 두 개 비교]**(상태 `scenMode`, 기본 두 개 비교): 하나만 보기를 고르면 시나리오 드롭다운이 하나(A·B 표시 없음)만 남고, 고른 시나리오의 지도 한 장을 크게(1280×800에서 285×470 두 장 → 582×522 한 장), 그래프에는 그 시나리오 선 하나(+현재기후), 숫자 카드에는 "SSP1-2.6 · 값 15.5℃ | 현재 대비 변화량 +2.4℃ (현재기후 13.1℃ 기준)"을 보여 줍니다. 나란히/차이 버튼, 두 시나리오 차이, 기간별 차이 막대(B−A)는 숨깁니다. 지역·기후요소·기간·값/변화량·연도 보기·4개 모두 보기·20년 평균선은 두 모드에서 똑같이 동작하고, 모드를 바꿔도 그대로입니다. 하나만 보는 동안에도 B 시나리오와 차이 지도 선택은 기억해 두었다가(`viewState`가 그릴 때만 감춤) 두 개 비교로 돌아오면 되살립니다. 하나만 보기에서 B로 기억된 시나리오를 고르면 A·B를 맞바꿔 둡니다(비교로 돌아와도 A ≠ B). 4개 모두 보기를 켜면 그래프에 고른 시나리오와 나머지 세 시나리오(가는 선)가 함께 보이고, 지도·숫자 카드는 고른 시나리오 하나 그대로입니다.
- **공통 조건 줄**(지도와 그래프에 함께 적용): 시나리오 A·B 드롭다운(얇은 테두리, 작은 A/B 표시, 지도·그래프와 같은 시나리오 색 점, 누르면 시나리오 창과 CO₂ 미니 그래프) · 기간 선택 버튼(고른 기간만 흰 바탕 + 진한 테두리). 기간을 고르면 그래프에 같은 구간 음영, 지도는 그 기간의 20년 평균입니다. 그래프를 눌러 연도 보기가 되면 기간 자리에 `2057년 보기 ✕`가 보이고, ✕를 누르면 기간 버튼으로 돌아옵니다. 2061~2080은 값을 만들 수 없으면 비활성화. 상단 높이는 가로 화면 105px(이전 112px), 세로 태블릿 153px(이전 206px). 1365px 이하(디벗 1280×800·1340×800)에서는 [하나만 보기|두 개 비교]가 들어가도록 "시나리오"·"기간" 글자를 화면에서만 숨기고 간격을 줄여, 두 개 비교 + 연도 보기에서도 공통 조건이 한 줄입니다(1024×768 가로의 두 개 비교는 두 줄).
- **지도 머리**: `[분석 지역: 서울 ▾]` + 작은 글씨 "지도를 눌러 바꿀 수 있어요" + `[전국으로]`(전국이면 비활성) + `[+ 비교 지역]`. `분석 지역: 서울 ▾`을 누르면 17개 시도 목록 창(특별시·광역시·특별자치시 / 도·특별자치도, 한 칸 52px 이상)이 열려 바로 고를 수 있고, 지도를 눌러 고르는 방법도 그대로입니다. 비교 지역을 고르면 `분석 지역: 서울 ▾ · 비교: 부산 ✕`. 선택한 지역은 A·B 두 지도 모두에서 흰 테두리 위 굵은 경계선(4px)으로 강조합니다.
- **지도**: 실제 시도 경계. 나란히 보기는 두 지도가 같은 크기·공통 범례(고정 색 범위), 차이(B−A)는 한 장을 크게. 17개 시도 이름을 모두 늘 표시합니다(14px, 특별·광역시는 진하게, 선택한 지역은 16px 굵게). 이름표가 겹치면 선택한 지역 > 시 > 도 순서로 자리를 잡고 뒤의 이름표를 가까운 빈자리(위·아래·옆)로 비켜 둡니다. 지도 크기가 바뀌면(화면 회전, 전체화면) 다시 맞춥니다. 지역 A는 굵은 테두리, 비교 지역 B는 점선 테두리 + A/B 배지. 지역을 누르면 그 자리에 "서울 · A … · B …" 말풍선이 잠깐 보입니다. 울릉도·독도는 오른쪽 위 상자(실제 축척)에 14px 이름표와 함께, 독도는 위치 동그라미로. 지도 영역이 520px보다 좁으면(1024×768 가로, 휴대폰) A/B 전환 탭으로 한 장씩 보고, `[나란히|차이]`는 탭과 같은 줄에 둡니다.
- **지도 색**: 변화량·차이(B−A) 지도는 0이 언제나 흰색이고, 범위는 요소·표시 방식마다 실제 최솟값~최댓값으로 고정(시나리오·기간을 바꿔도 그대로)입니다. 최솟값이 0 이상이면 0부터 한쪽 방향(예: 평균기온 변화량 0.0~+6.7), 양쪽에 걸치면 0의 위치를 범례 막대 위에 표시합니다(대칭으로 늘리지 않음). 값 모드는 한쪽으로 진해지는 색 그대로.
- **그래프 제목**: 조건 전체를 한 줄로 — "서울 · 평균기온 · 현재 대비 변화량"(비교 중이면 "서울·부산 비교 · …").
- **그래프 기본 화면**: A·B 연도별 선, 현재기후(2000~2019) 선, 0 기준선, 선택 기간 음영 — 연도별 변화 추세가 먼저 보이게 합니다. 범례에는 켜진 층만 보입니다.
- **그래프 보기 옵션**: `☐ 4개 모두 보기`(나머지 두 시나리오를 가는 선으로 더함, 지역 비교 중에는 비활성) · `☐ 과거 관측 보기(1912~)` · `☐ 20년 평균선 표시` · ⓘ. 셋 다 기본 꺼짐이고 제목을 누르면 꺼짐으로 돌아갑니다.
- **과거 관측 보기(1912~)**: 기본 꺼짐(가로축 2000~2100). 켜면 가로축이 1912년부터가 되고 6개 지점 관측(옅은 회색 가는 점선 + 작은 점, "관측 · 6개 지점 평균(지점값)" 이름표)과 지점 선택 목록이 보입니다. 장기관측이 있는 요소(평균기온)에서만 켤 수 있습니다.
- **현재기후 선**: 진한 회색 굵은 실선에 "현재기후 · {지역} 평균(2000~2019)" 이름표. 전망 선과 겹치지 않게 선 위나 아래에 붙습니다.
- **20년 평균선 표시**(상태 `periodBars`): 끄면(기본) 선택한 기간을 포함해 20년 평균 가로선을 하나도 그리지 않고 연도별 전망 선만 보입니다. 선택 기간 음영, 지도, 핵심 수치의 기간 평균값은 그대로입니다. 켜면 모든 기간(전반기·중반기·2061~2080·후반기)의 A·B 가로선과 범례 "▬ 20년 평균"(2061~2080은 연하게 "20년 평균(앱 계산)")이 보이고, 선택한 기간은 진하고 굵게(4px), 다른 기간은 옅고 가늘게(2.5px, 반투명) 그립니다. 연도 보기에서 켜면 고른 기간이 없어 모두 옅게 그립니다. 전국처럼 연도별 값이 없는 지역은 이 가로선이 유일한 자료라 늘 그리고, 그동안 체크박스는 켜진 채 비활성으로 보입니다.
- **시계열 그래프**: 관측·현재기후·시나리오는 서로 다른 데이터셋이고 선을 잇지 않습니다. 결측은 끊김. 범례는 그래프 안 왼쪽 위, 긴 설명은 ⓘ 안. 그래프를 누르면 연도 보기(지도도 그 연도로). 그해의 값은 숫자 카드 한 자리에 보이고, 공통 조건 줄에는 기간 버튼 옆에 `2014년 보기 ✕`가 덧붙습니다(기간 버튼을 누르면 연도 보기가 풀림).
- **지역 이름**: 그래프 제목·현재기후 이름표·말풍선·핵심 수치·그래프 ⓘ는 모두 선택한 지역을 따릅니다(고정 지역 이름 없음). 관측 이름표만 "6개 지점 평균"으로, 지역과 무관한 자료임을 밝힙니다.
- **숫자 카드**(오른쪽 패널, 제목 바로 아래 · 순서: 제목 → 숫자 카드 → 체크박스 줄 → 그래프): 머리 줄에 무엇의 값인지("후반기(2081~2100) · 20년 평균" 또는 "2057년 · 기후모델 전망"), 그 아래 A 값, B 값, "두 시나리오 차이"(B−A)를 크게(30px), 괄호 안 값은 그 아래 작게. 2061~2080을 고르면 작은 글씨 "앱 계산값". 비교 지역이 있으면 지역마다 한 줄. 칸이 좁으면 칸째로 다음 줄로 넘어가 겹치지 않습니다. 머리 줄 오른쪽 끝 `[▾ 기간별 표]`를 누르면 지도·그래프 아래에 그래프 제목과 같은 조건(예: "기간별 표 · 대구 · 평균기온 · 현재 대비 변화량")을 머리에 단 기간 × 시나리오 표, 기간별 차이 막대(B−A), 보조 분석 자리(준비 중)가 펼쳐지고 그 자리로 내려갑니다(표 칸을 누르면 기간 변경).
- **현재기후(현재 기간, 2000~2019년)**: 시나리오와 무관하므로 A·B로 나누지 않고 한 값만. 연도 보기면 "2014년 15.5일 (현재기후 평균 31.2일보다 15.7일 적음)"(변화량 모드여도 같은 형식), 현재 기간이면 "31.2일 (변화량의 기준값)". "두 시나리오 차이" 칸은 "현재기후 자료 — 시나리오와 무관". 2020년은 "자료 없음", 과거 관측 연도(1912~1999)는 관측값 하나.
- 세로 화면(800×1280)·좁은 화면: 띠 → 머리 막대(제목 / 기후요소 탭·값/변화량) → 공통 조건 → 지도 두 장(화면 폭 전체) → 숫자 카드·그래프 → 접힌 표. 머리글은 스크롤해도 위에 붙어 있습니다. 세로 태블릿에서는 공통 조건이 한 줄에 들어가도록 "시나리오"·"기간" 글자를 화면에서만 숨기고(읽기 도구에는 남김), 휴대폰에서는 탭 줄과 공통 조건 줄이 각각 한 줄 가로 스크롤이 됩니다(A·B는 한 화면에 보임).
- 첫 화면(제목을 눌렀을 때 돌아가는 기본 상태): 서울 · 평균기온 · SSP1-2.6 vs SSP5-8.5 · 2081~2100 · 값, 두 개 비교, 4개 모두 보기·과거 관측·20년 평균선 표시 모두 꺼짐.
- 2061~2080은 공식 20년 값이 없어 앱이 계산한 값입니다. 기간 버튼 옆 ⓘ를 누르면 "이 기간은 기상청 공식 기간값이 없어, 연도별 전망값의 20년 평균을 앱이 계산한 값입니다."가 열리고, 자세한 계산 방법(`derived.p3.method`)은 그래프 ⓘ 안에 보여 줍니다.
- **공통 범례 ⓘ**: "지도 색은 시나리오를 구분하는 색이 아니라 현재 대비 상승량입니다. 두 지도는 같은 색 범위를 씁니다."(평균기온 변화량 기준. 값 모드는 "각 지역의 ○○ 값", 다른 요소의 변화량은 "현재 대비 변화량"·"변화율").
- **그래프 아래 설명** 끝에는 "연도별 선은 기후모델 전망값이며, 그해의 실제 날씨를 예보한 것이 아닙니다."를 붙입니다. 두 시나리오 선 사이는 채우지 않고, 지도에 칠한 기간의 회색 띠만 둡니다.
- **터치 기기(디벗) 기준**: 마우스를 올려야 보이는 설명(`title`)은 쓰지 않습니다. 짧은 설명은 화면에 바로 쓰고, 긴 설명은 눌러서 여는 ⓘ 창에 둡니다.
- 글자: 기본 16px, 보조 최소 14px. 누름 대상 최소 44×44px.

앱에서 계산한 값에는 "앱 계산" 표시가 붙습니다: 2061~2080 값(숫자 카드는 "앱 계산값"), 차이 지도·기간별 표의 시나리오 차이 B−A, 지역 차이 A−B. 핵심 수치 줄의 "두 시나리오 차이"에는 붙이지 않습니다.
변화량은 같은 지역·같은 요소의 현재기후(2000~2019) 공식값을 기준으로 합니다.

## 실제 데이터로 교체하는 방법

**코드를 고치지 않고 `data/` 파일만 같은 형식으로 바꾸면 됩니다.** (기상청 자료 가공 스크립트가 만든 실제 형식의 파일로 바꿔서 코드 수정 없이 동작하는 것을 확인했습니다 — 저장소에는 넣지 않음.)

1. 아래 형식대로 JSON을 만들어 같은 경로에 덮어씁니다.
2. 모든 파일에서 `"mock": true`를 지우거나 `false`로 바꿉니다. **하나라도 `true`가 남아 있으면 경고 띠가 계속 보입니다.**
3. `manifest.json`의 `version`을 새 문자열로 바꿉니다(예: `"2026-12-01"`). 브라우저·CDN 캐시를 새로 받게 하는 열쇠입니다(아래 「캐시」).
4. `python3 -m http.server`로 열어 경고 띠가 사라졌는지, 콘솔 오류가 없는지 확인합니다.

### `data/manifest.json`

`regions`(code·name·short), `scenarios`(id·label·level·color·co2_2100_ppm), `elements`(id·name·unit·kind·file), `periods`(id·label·start·end, 계산 구간은 `"derived": true`), `sources`, `version`, `mock`.
요소 `kind`: `temp`(장기관측 겹쳐 보기는 이 요소에서만), `prcp`(mm/% 전환), `days`(값 모드 y축 0부터).

**지역 코드는 기상청 원자료 파일의 코드를 그대로 씁니다**: 11 서울, 21 부산, 22 대구, 23 인천, 24 광주, 25 대전, 26 울산, 29 세종, 31 경기, 32 강원, 33 충북, 34 충남, 35 전북, 36 전남, 37 경북, 38 경남, 39 제주. 행정표준코드(부산 26, 경기 41 등)와 숫자가 다르니 섞지 마세요. 전국은 앱 내부 코드 `"00"`입니다. 지도 파일(`geo/`)의 `code`도 같은 코드를 씁니다.

### `data/elements/{id}.json`

```jsonc
{
  "element": "tavg", "unit": "℃",
  "current":    { "startYear": 2000, "annual": { "00": [20개, 2000~2019], "11": [...] } },
  "projection": { "startYear": 2021, "annual": { "ssp126": { "00": [80개, 2021~2100] }, "ssp245": {}, "ssp370": {}, "ssp585": {} } },
  "official": {
    "cur": { "00": 11.9 },                                        // 현재기후(2000~2019) 공식값 = 변화량의 기준
    "periods": { "ssp126": { "p1": { "00": 13.2 }, "p2": {}, "p4": {} } },
    "decades": { "ssp126": { "2061": { "00": 13.9 }, "2071": {} } } // 키 = 10년 구간 시작 연도
  },
  "scale": {                                                       // 모두 [최솟값, 최댓값], tools/rescale.py가 계산
    "period": { "abs": [10.5, 21.9], "chg": [1.1, 6.7], "diff": [-4.3, 4.3] },   // 기간 지도·막대 (강수량은 pct·pctDiff도)
    "annual": { "abs": [9.7, 23.3], "chg": [-0.9, 8.0], "diff": [-6.1, 6.1] }    // 연도 보기 지도 (값은 실제 평균기온)
  }
}
```

앱은 기상청 자료 가공 스크립트(`build_app_data.py`)가 내는 아래 변형도 그대로 받습니다.

| 항목 | 위 형식 | 함께 받는 형식 |
|---|---|---|
| `scale` | `{ "period": {…}, "annual": {…} }` (기간 지도·막대는 `period`, **연도 보기 지도는 `annual`**) | 하나로 된 `{abs, chg, …}`, 예전 대칭 형식(`"chg": 6.5` → [−6.5, 6.5]로 읽음) |
| `decades` | `[시나리오][구간 시작 연도][지역]` | `[시나리오][지역][구간 시작 연도]` |
| 2061~2080(`p3`) | `decades` 2061·2071 평균을 앱이 계산 | `official.periods[시나리오].p3`에 **미리 계산된 값이 있으면 그 값**을 씀 (어느 쪽이든 "앱 계산" 표시). `derived.p3.method`가 있으면 그 설명을 그래프 ⓘ·기간별 표 아래에 보여 줌 |
| 그 밖의 키 | — | `name`, `derived`, `notes` 등 더 있어도 무시 |

- 값이 없으면 `null`. 앱은 메우지 않고 선을 끊거나 "자료 없음"(지도 빗금)으로 보여 줍니다.
- **전국(`"00"`)은 `official`(기간값·10년 값)에만 넣고 `annual`에는 넣지 않아도 됩니다.** 기상청 시도 연자료 파일에는 전국 열이 없기 때문입니다. `annual`에 `"00"`이 없으면 그래프는 전국 연별 선 없이 공식 20년 평균 막대만 그리고 "전국은 기간 평균값만 제공됩니다"를 표시합니다(4개 모두를 켜면 나머지 두 시나리오도 가는 막대로). 앱은 시도 값을 평균해 전국을 만들지 않습니다. 나중에 전국 연별 값을 구하면 `annual`에 `"00"`을 넣기만 하면 선이 그려집니다.
- 2020년은 배열에 넣지 않습니다(현재기후 2000~2019, 전망 2021~2100).
- 2061~2080 값을 만들 수 없으면(미리 계산된 값도, 2061·2071 10년 값도 없으면) 공통 조건 줄 기간 버튼의 2061~2080이 비활성화됩니다.
- **`scale`은 `python3 tools/rescale.py`로 미리 계산**합니다(`data/` 파일을 바꾸면 다시 돌리고 `manifest.json`의 `version`도 바꿈). 4개 시나리오 × 모든 기간(현재·전반기·중반기·2061~2080·후반기) × 모든 지역에서 실제 최솟값·최댓값을 구해 소수 1자리로 바깥쪽 반올림하고, 기간(`period`)과 연도별(`annual`)을 따로 둡니다. 앱은 이 고정 범위를 그대로 써서 시나리오·기간을 바꿔도 색 범위가 흔들리지 않습니다.
  - `abs` 값 [최소, 최대] / `chg` 값 − 현재 / `diff` 같은 지역·기간의 B − A(서로 다른 두 시나리오의 모든 순서쌍이라 저절로 대칭) / `pct` 변화율(%) / `pctDiff` 변화율 차이(%p)
  - 앱은 0을 언제나 흰색으로 둡니다. 최솟값이 0 이상이면 [0, 최댓값] 한쪽 방향, 최댓값이 0 이하이면 [최솟값, 0] 한쪽 방향, 양쪽에 걸치면 0을 흰색으로 한 비대칭 양방향.
  - 연도 보기에서 1년 값이 범위를 넘으면 양 끝 색으로 칠하고 범례에 그 사실을 적습니다.
  - `scale`이 빠지면 앱이 요소마다 한 번 계산해 고정하지만(콘솔 경고), 실제 데이터에는 넣어 주세요.

### `data/obs/stations.json`

`valueType: "anomaly"`, `baseline: "2000-2019"` — 지점 관측값을 **각 지점의 2000~2019 평균 기준 편차**로 넣습니다(원자료의 1991~2020 평년 대비 편차를 전처리에서 옮긴 값). `series`의 키(`6avg`, `108` …)가 관측 선택 목록이 되고 `name`이 그대로 이름표가 됩니다. 결측은 `null`.

### `data/co2/emissions.json`

`years` 배열을 x축으로 그대로 씁니다(간격이 달라도 됨). `values`는 시나리오 id별 배열. 시나리오 선택 창의 미니 배출 곡선에만 쓰이며 처음 창을 열 때 불러옵니다.

### `data/geo/sido.json` — 실제 시도 경계 (예시 아님)

admdongkor(통계청 SGIS 행정동 경계 가공, CC BY 4.0) 2024-04-01 버전(2024년 6월 시점)을 `tools/build_geo.py`로 시도 17개 SVG 경로로 가공한 파일입니다(29.7 KB). 출처·기준 시점·라이선스·가공 방법은 **`data/geo/README.md`**에 있습니다. 지도 코드는 기상청 원자료 코드입니다.

```jsonc
{ "type": "paths", "mock": false, "viewBox": "0 0 1000 1283",
  "paths": [{ "code": "11", "name": "서울", "d": "M…z", "label": [x, y] }],
  "insets": [{ "name": "울릉도·독도", "box": [x, y, w, h], "points": [{ "name": "독도", "x": 0, "y": 0 }] }] }
```

- 미리 투영된 좌표라 앱 실행 중 투영 계산이 없습니다. 이름표 위치는 `label`(없으면 경로 가운데).
- 경계를 다시 만들려면 `data/geo/README.md`의 명령을 따릅니다(네트워크 필요).

### 예시 데이터 (`data-mock/`)

```bash
python3 tools/make_mock.py           # data-mock/ 에 씀 — data/의 실제 자료는 건드리지 않음
python3 -m http.server 8000          # http://localhost:8000/?data=mock 으로 예시 데이터 보기
```

`?data=mock`이면 기후 값 파일을 `data-mock/`에서 읽고 지도 경계만 `data/geo/`에서 읽습니다. `data-mock/`은 `.gitignore`·`.vercelignore`에 들어 있어 배포 주소에서는 이 주소가 "자료를 불러오지 못했어요"가 됩니다.
값을 만드는 규칙(직선 추세 + 작은 흔들림)과, 일부러 넣은 상황(2020년 없음, 관측 1950~1953 결측, 기간에 따라 시나리오 순서 바뀜, 기간별 차이가 줄었다 커짐, 한파일수 세종 null, 폭염일수 10년 값 없음, 전국은 annual 없이 official에만)은 스크립트 맨 위 주석에 있고, 실행할 때 자동으로 확인합니다.

## 캐시 (`vercel.json`)

- `data/manifest.json`: 매번 서버에 새 버전이 있는지 확인(`max-age=0, must-revalidate`).
- 나머지 `data/*`: 하루 캐시(`max-age=86400, stale-while-revalidate=604800`).
- 앱은 manifest를 받은 뒤 나머지 파일을 `?v=<manifest.version>`을 붙여 요청합니다. **데이터 파일을 바꿀 때 `version`만 바꾸면** 이전 캐시와 상관없이 새 파일을 받습니다. `version`을 안 바꾸면 최대 하루 동안 이전 파일이 보일 수 있습니다.
- `.vercelignore`로 `tools/`, `tests/`는 배포하지 않습니다.

## 성능 — 첫 접속 전송량

첫 접속에는 `manifest.json`, `geo/sido.json`, `elements/tavg.json`, `obs/stations.json`만 받습니다.
다른 요소 파일은 그 칩을 처음 누를 때, `co2/emissions.json`은 시나리오 선택 창을 처음 열 때 받고, 한 번 받은 파일은 메모리에 두고 다시 받지 않습니다(같은 파일을 동시에 두 번 요청하지 않음).
